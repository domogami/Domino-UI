# Hosting the component notebook

The maintained hosting guide is [Deploy Domino UI](DEPLOYMENT.md), covering the Netlify project, `ui.dominicklee.net`, build settings, DNS, verification, and rollback.

Keep the visual notebook and reusable components together in this repository. The portfolio, Quartz garden, and Obsidian theme consume deliberate versions of the shared system independently. Publishing the notebook does not migrate those applications. See [adoption](ADOPTION.md) for supported Git installs, packed builds, and native adapters.
